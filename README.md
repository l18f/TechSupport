# TechSupport

A web-based technical support system for creating, managing, searching, and tracking support tickets.

## About the Project

TechSupport is a simple web-based technical support system designed to help users submit technical support tickets and allow support staff to manage and track them easily.

This project was developed as a graduation project for the Computer Technical Support specialization.

## Features

- User login system
- Create support tickets
- View ticket details
- Update ticket status
- Search support tickets
- Dashboard statistics
- Knowledge base
- Contact form
- LocalStorage data management
- Responsive design
- Arabic interface
- Light and dark theme

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages
